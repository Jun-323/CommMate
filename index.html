为嵌入式开发者而生

串口、终端、网络、MQTT、参考资料——五合一，一个工具全部搞定

串口调试

支持全部标准串口参数配置，HEX / ASCII 双模式收发。超时帧与流模式两种分帧策略，适配 AT 指令与透传场景。实时热插拔检测，插拔即刷新端口列表。

TCP / UDP 网络

TCP Client、TCP Server、UDP 三种模式一键切换。TCP 支持多客户端连接管理，UDP 支持广播收发，提供 5 秒超时保护与后台任务自动清理。

AT 指令脚本引擎

自定义 DSL 语法，支持 SEND / EXPECT / WAIT / SET 变量 / IF GOTO 控制流 / REPEAT WHILE 循环。脚本按品牌型号管理，内置编辑器，支持导入导出 .cmds 文件，在线脚本库持续更新。

离线速查表

内置 5 类离线速查手册：ASCII 码表、Git 命令、Linux 命令、Android 调试、WiFi 调试——500+ 条命令，无需联网，选中即复制。

日志记录

完整收发日志带毫秒级时间戳，HEX 与 ASCII 双栏对照显示，支持复制与导出为文本文件。发送字节数实时统计，方便问题回溯。

中英双语 & 主题切换

完整中英文界面，自定义 MarkupExtension 实现运行时语言切换。亮色 / 暗色双主题，DynamicResource 驱动即时生效，无闪烁。

多面板并行

串口、网络、脚本、速查四个功能面板独立运行互不干扰。全局端口互斥机制防止同一端口被多个面板同时占用，安全可靠。

完全免费

完全免费，无广告无弹窗无捆绑。.NET 10 WPF 原生开发，启动快内存低，专注工具本身。

快捷键速查表

内置 CommMate 全部快捷键速查表，覆盖串口、网络、终端、脚本四大面板快捷键，一键打开随时查阅，无需记忆。

技术亮点

不仅功能全面，代码本身也是一份 WPF MVVM 的实践参考

MV

严格 MVVM 架构

基于 CommunityToolkit.Mvvm 源生成器，零样板代码。Models / Services / ViewModels / Views 四层分离，职责边界清晰。

⚡

后台线程 Offload

HEX / ASCII 转换在数据接收线程完成，BeginInvoke 异步投递 UI 更新，不阻塞接收线程，高频数据场景吞吐量优异。

DSL

自定义 DSL 脚本引擎

手写词法分析器 + 递归下降语法分析器，支持变量、正则匹配、控制流、循环。脚本树文件浏览器 + 文件监控自动刷新 + 在线脚本库。

⏱

智能分帧引擎

超时模式静默期后整包输出，专为 AT 指令响应优化；流式模式即时转发，适用透传场景。根据调试场景自由切换，精准控制数据边界。

🛡

三层异常兜底

UI 线程、后台 Task、AppDomain 三层未处理异常全局捕获。串口 / 网络 I/O 带超时保护，Dispose 模式确保资源正确释放。

MQ

原生 MQTT 调试

完整支持 MQTT 3.1.1 协议，提供主题订阅、发布、通配符匹配。实时消息监控带 QoS 级别标记，支持保留消息与遗嘱消息配置。

常见问题

需要安装 .NET 运行时吗？
CommMate 需要 .NET 10 Desktop Runtime 才能运行。请先前往 微软官网 下载安装，Windows 10/11 64 位系统均支持。
CommMate 和市面上的串口助手有什么不同？
集串口通信、TCP/UDP 网络、离线速查表于一体，无需在多个工具间切换。MVVM 架构清晰，无广告无捆绑。
支持 Windows 7 吗？
不支持。CommMate 基于 .NET 10 构建，仅支持 Windows 10 1809 及以上版本的 64 位系统。
支持 macOS 或 Linux 吗？
目前仅支持 Windows。CommMate 使用 WPF 框架，这是 Windows 原生 UI 技术。跨平台版本暂无计划。
收费吗？有广告吗？
完全免费，无广告、无弹窗、无捆绑。如有问题欢迎通过官方渠道反馈。
