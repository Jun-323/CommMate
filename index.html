为嵌入式开发者而生

从串口调试到网络通信，一个工具全部搞定

串口调试

支持标准串口参数配置，HEX/ASCII 双模式收发，自动分帧显示，AT 命令一键发送。

TCP/UDP 网络

TCP Client/Server、UDP 收发一键切换，支持多连接管理，实时通信状态监控。

日志记录

完整收发日志带时间戳，支持导出为文本文件，方便问题回溯和团队协作。

多会话管理

同时管理多个串口和网络连接，标签页切换，各会话独立运行互不干扰。

轻量高效

基于 .NET 10 WPF 原生开发，启动快、占用低。需安装 .NET 10 Desktop Runtime 方可运行。

常见问题

需要安装 .NET 运行时吗？
CommMate 需要 .NET 10 Desktop Runtime 才能运行。请先前往微软官网下载安装，Windows 10/11 64 位系统均支持。
支持 Windows 7 吗？
不支持。CommMate 基于 .NET 10 构建，仅支持 Windows 10 1809 及以上版本的 64 位系统。
支持 macOS 或 Linux 吗？
目前仅支持 Windows。CommMate 使用 WPF 框架，这是 Windows 原生技术。跨平台版本暂无计划。
收费吗？有广告吗？
完全免费，无广告、无弹窗、无捆绑。如有问题欢迎通过 GitHub Issues 反馈。
