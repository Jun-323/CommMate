Privacy Policy

最后更新：2026-06-25

概述

CommMate（"本应用"）是一款本地运行的 Windows 串口与网络调试工具。我们高度重视用户隐私，本策略说明本应用如何处理用户数据。

本应用收集哪些数据？

简答：不收集任何数据。

  • 不收集个人信息 — 本应用不需要账号注册，不收集姓名、邮箱、IP 地址或任何可识别个人身份的信息。
  • 不上传数据 — 所有串口通信数据、网络通信数据仅在您的本地设备上处理和显示，不会发送到任何远程服务器。
  • 不嵌入分析 SDK — 本应用不含任何第三方分析、广告或追踪组件。

本地存储的数据

为了记住您的使用偏好，本应用会在您的本地设备上保存一个配置文件：

  • 文件位置：%LOCALAPPDATA%\CommMate\commmate.json
  • 包含内容：界面主题（亮色/暗色）、语言偏好（中文/英文）、最近使用的串口/网络配置、快捷命令列表、窗口布局设置。
  • 不包含的内容：通信日志、收发数据、密码或任何敏感信息。（通信日志仅当您主动通过"保存"按钮导出时才写入您指定的位置。）
  • 此文件完全存储在您的本地设备上，不会上传到任何服务器。
  • 卸载本应用后，您可以手动删除此目录以清除所有残留配置。

网络访问

本应用在以下极少数场景下会访问网络：

  • 检查更新 — 当您手动点击"检查更新"时，本应用会向 GitHub Releases API 发送一次 HTTPS 请求以获取最新版本信息。此请求不包含任何个人数据。
  • 串口 / 网络通信 — 作为调试工具，本应用会根据您的操作发起串口通信或 TCP/UDP 网络连接。这些通信完全由您控制，应用不会自动发起任何网络连接。

本应用不会在后台自动联网、不会上报使用统计、不会进行任何形式的遥测。

第三方服务

本应用不集成任何第三方分析、广告或数据追踪服务。唯一的第三方依赖是 .NET 运行时库（Microsoft 提供），其隐私策略请参见 Microsoft 隐私声明。

数据的共享与披露

本应用不收集个人数据，因此不会、也无法与任何第三方共享您的数据。我们不会出售、出租或交易任何信息。

儿童隐私

本应用不会故意收集 13 岁以下儿童的个人信息。如果您认为我们无意中收集了此类信息，请联系我们以便立即删除。

政策更新

本隐私策略可能会不时更新。更新后的版本将发布在此页面，并在页面顶部标注更新日期。
